# Решения автора по новой модели статусов и бенчмарку

Источник: обсуждение 2026-10-13. Это контракт для разметки бенчмарка и для редизайна классификатора.
Подробности и обоснования — `tmp/status-design-2026-10-13/PROPOSAL.md` (до этих решений).

## Колонки

- `status` (итог): `resonant`, `transient`, `near_separatrix`, `non_resonant`, `uncertain`, `invalid`.
  - `transient` — резонансный объект, пусть временно. `near_separatrix` — не резонанс, а похожее; отдельный статус.
  - `invalid` вместо `chaotic`: классификация невозможна при этих параметрах (алиас, нефизическая орбита, неопределённая фаза); причина в `reason`.
- `confidence`: `certain` / `high` / `medium` / `low`; пусто при `uncertain`/`invalid`.
  - `certain` — ручная проверка не нужна никогда: 0 ошибок на бенчмарке (≥ 30–40 примеров в ячейке), все критерии с запасом; одна найденная ошибка снимает `certain` с правила до исправления. Цель — перевести в `certain` как можно больше, но за счёт качества.
  - `high` — все проверки пройдены, но хотя бы одна на тонком запасе (причина в `reason`), точность ≥ 97–98 %. В массовых исследованиях не проверяется; при изучении отдельных объектов проверяется.
  - `medium` ≥ 90 % — выборочно; `low` — без обещаний, целиком в массовом исследовании.
- `angle_status`: `libration`, `transient`, `near_separatrix`, `circulation`, `drift`, `insufficient_time`, `undefined`.
  - `slow_circulation` упразднён: ≥ 1 оборота — `circulation`; < 1 — `insufficient_time`.
  - Подтипы: libration `stationary`/`modulated`; insufficient_time `arc`/`stall`/`few_cycles`; undefined `alias`/`unphysical`/`undefined_phase`.
- `checks` — колонки по типу резонанса, пусто для чужих типов; значения `pass`/`fail`/`not_measured`/`not_applicable`.
  - MMR: портрет/отклик a на σ (`check_mmr_a_response`: медленную часть σ даёт a, а не p·ϖ̇) + геометрия петли; алиас-guard.
  - Secular: отклик e (или i) на σ (ė ∝ sin σ) против окружности постоянного радиуса (кинематика).
  - ZLK: free-omega gate (решающая) + антикорреляция e–i (подтверждающая; при либрации без антикорреляции — флаг ложноположительного). Для коротких рядов — проверка во временной области (корреляция медленных e(t), i(t), сохранение √(1−e²)cos i), с пометкой числа циклов.
- `reason`, `action` (`none`/`spot_check`/`review`/`extend`/`resample`), `status_code` временно; обратная совместимость не нужна, чистота кода важнее; `status` становится строкой сразу.
- Метрики (TTO, rev_true и прочие нынешние) остаются в summary.
- `episodes.csv` — делаем.

## Правила

- **Всё пересчитывается из итоговых CSV/JSON без интегрирования**: классификация, графики.
- Эпизод (либрация/транзиент): **≥ 3 точек поворота** (не 4). Случаи на 3 точках получают не выше `high`, с `reason`.
- Транзиент требует того же, что и либрация (3 точки поворота).
- Либрация «на весь интервал»: эпизод начинается не позже одного периода либрации от начала и кончается не раньше одного периода от конца (не «90 %»).
- Кинематическая либрация (угол ограничен геометрией/ϖ̇/навязанным колебанием a, без динамики) — для всех типов одинаково: `angle_status=libration`, `status=non_resonant`, `reason=kinematic_libration`. ZLK −2 сюда же.
- `drift` с доказанным кинематическим механизмом (центр уходит из-за ϖ̇, a не отвечает) → `non_resonant`. Без доказанного механизма → `uncertain` + `extend`.
- Алиас: если ожидаемая скорость угла по среднему a однозначно далека от резонанса — `non_resonant`, `reason=alias`; иначе `invalid/alias` + `resample`. Finder предупреждает до интегрирования.
- Длинные либрации, где 3 точки поворота не набираются на базе (пример: 363 Padua, z1, P ~ 10 Myr на 10 Myr) → `uncertain` + `extend` (`baseline_needed`).
- e–i не измерима совсем → `uncertain` + `extend` (не `fail`).
- Free-omega gate `UNAVAILABLE` → `uncertain` (−9), `reason=gate_unavailable`, action по причине (обычно `extend`).
- Если не можем сказать с уверенностью — помечаем; если принципиально не можем — warning.
- Метка бенчмарка относится к той же записи (регим: интегратор, база, шаг, эпоха), что и ряд. Метки с других прогонов — только как подсказка.
- q_max для соседних аргументов — из настроек симуляции. Силу резонанса по Gallardo не используем.
