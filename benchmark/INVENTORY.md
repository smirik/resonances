# Benchmark v2: инвентаризация кандидатов

Дата: 2026-10-13. Сборка: `build_candidates.py` (raw/*.json → `candidates.csv`, `dropped.csv`).

## Что есть в этой папке

| файл | что там |
|---|---|
| `raw/<source>.json` | 10 исходных выгрузок (sweep), дословно, 1810 записей |
| `candidates.csv` | 770 строк, одна на (name, resonance), колонки по заданию + `confidence` |
| `dropped.csv` | 71 почти одинаковая алгоритмическая строка, убранная при прореживании |
| `build_candidates.py` | правила слияния, нормализация имён/резонансов, ручные OVERRIDES |

Слияние: имена нормализованы (`1999 UJ7 (121514)` → `121514`, `624 Hektor` → `624`), резонансы приведены к полной
форме по Д'Аламберу (`2J-1` → `2J-1+0-1`, `4J-2S-1` → `4J-2S-1+0+0-1`), все варианты ZLK (`omega`, `lkr`, `LK (omega)`)
→ `LK`. Вердикт автора важнее любых алгоритмических меток. Для строк бенчмарка primary/acceptable берутся прямо из
`benchmark/raw/old_ground_truth.csv` (until 2026-10-16 `tests/resonances/benchmark/ground_truth.csv`). 115 случаев разобраны вручную (OVERRIDES).
Прореживание: если больше 5 строк совпадают по rtype, резонансу и статусу и у них нет вердикта автора,
оставлено 5. Сколько выброшено и какие имена, записано в `notes` оставшихся.

## Предлагаемая раскладка

```
<root>/<rtype>/<bucket>/<confidence>/<id>__<name>__<resonance>/
    series.csv.gz     только колонки для классификатора
    combined.png      combined-график (уменьшить до 2560 px по ширине)
    meta.json         name, resonance, rtype, bucket, confidence, author_verdict (дословно), sources,
                      reliability, old_statuses, интегратор/span/шаг/эпоха/источник элементов, tags, notes,
                      sha256 исходного файла
```
`rtype` ∈ mmr2, mmr3, coorbital, secular, zlk. `bucket` — 9 папок из задания. `confidence` ∈ high, medium, low.
Синтетику (`model:*`) держать отдельно, генераторами в тестах, а не файлами.

Колонки `series.csv.gz` по типам:
- mmr2/mmr3/coorbital: `times, a, e, <res>_angle` (угол в разрезе [0, 2π); unwrapped и filtered классификатор
  пересчитает сам), шаг исходный;
- secular: `times, a, e, inc, varpi, Omega, <res>_angle` (proper). Для 10–50 млн лет прорежать до 500 лет: быстрые
  вынужденные члены (≈50–300 тыс. лет) и либрации от 300 тыс. лет сохраняются. Фазы планет (`g_j t + phase`) писать
  в meta.json или отдельным `planets.csv.gz` (если `measured`);
- zlk: `times, a, e, inc, Omega, omega, LK_angle` (как фикстуры free-omega), шаг 100 лет.
