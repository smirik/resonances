# Примеры для статьи

Реестр случаев для одной или нескольких статей по классификатору v2 (просьбы автора 2026-10-15, п. 8, и 2026-10-31,
g05-7, g06-3). Примеры разложены по темам статьи. На строку: id примера (`benchmark/data/examples/<id>`), статус в
прогоне W28 и метка автора, одна строка формулировки, числа.

**Откуда числа.** Только из прогона W28: `benchmark/data/v2-w28` (`tools/reclassify.py`, 2026-11-01, 725 примеров,
settings_hash `1d85dd75ce00`; файлы `summary.csv`, `episodes.csv`, `mmr_numbers.csv`) и `benchmark/data/v2-w28-secular-zlk`
(ZLK). Перед статьёй числа перечитать из последнего прогона. Обозначения: P — период цикла, ТП — точки поворота,
L4 — R² закона силы по двум половинам записи, B1 — отклик a (измеренный/нужный маятнику), str — во сколько раз
нужная сила больше теоретической, K/K_th — закон силы 1:1, R²_E — интеграл энергии 1:1, Ψ — комбинация без λ тела.

**Метки.** «автор:дата» — метка автора на этой записи (`author_label_decisions_2026-10-15.csv`); статус W28 —
алгоритмический. «Кандидат» — автор согласился запомнить случай (s-3, 2026-10-31), но формулировка ждёт
пересборки папки рисунков.
