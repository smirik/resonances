    Rule index¶

    Start with the physics

    This page lists the rule IDs that appear in the combined figure, in decision_path, in rec_rule and in the output columns, each with a one-line meaning, its settings, the page that explains it and the code that runs it. The physics and the formulas are on the pages of How the status is determined; the values of the settings are in Configuration and resonances/.env.dist. The column rules_fired names the rules that acted on a row by meaning; their doc ids are the IDs on this page.

    Code paths are relative to resonances/resonance/analysis/. MMRs (two-body, three-body, retrograde, co-orbital) go through analyse_mmr (mmr/analyse.py; the order of its steps: Overview). Secular and Lidov-Kozai angles share the geometry, the ledger and the confidence rule and have their own signal step and physics (Secular and Lidov-Kozai).

    The verdict¶

    The verdict fields (status, angle_status, angle_subtype, reason, libration_origin, origin_detail, confidence, action, …) are described on the Overview; every reason with its status and origin is in Every reason; the old integer status_code is in Legacy integer codes. Every column of the output files is in Output data.

    The right column of the combined figure prints an ID as short name [id] and the deciding leaf as decided: circulation (C), so that it reads without this page; the IDs, decision_path and the CSV columns keep the code's spelling. A prefix appears only where IDs collide: the secular and Lidov-Kozai margins are SZ.N … SZ.G (MMR has its own N, S, F), a cap is cap:<key>. A path of the tree is named part by part (5d/6: force measured → judged by behavior). The names live in resonances/plotting/verdict_vocab.py (RULE_NAMES); an ID without one prints as unmapped check.
